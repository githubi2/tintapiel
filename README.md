# Tinta Piel

Spanish-language tattoo inspiration and AI virtual try-on — [tintapiel.com](https://tintapiel.com)

Guías honestas de tatuajes de león y leona en la pierna (significado, estilos, dolor, precio) más un probador virtual que muestra el diseño sobre una foto real antes de sentarse en la silla.

- Guías: [Tatuaje de león en la pierna para mujer](https://tintapiel.com/tatuaje-de-leon-en-la-pierna-para-mujer/) · [Tatuaje de leona en la pierna](https://tintapiel.com/tatuaje-de-leona-en-la-pierna/) · [Tatuajes de leones en la pierna](https://tintapiel.com/tatuajes-de-leones-en-la-pierna/)
- Herramienta: [Probador de tatuajes virtual con IA](https://tintapiel.com/tools/probador/)
- Planes: [Planes y créditos](https://tintapiel.com/pricing/)

Sitio estático (HTML + CSS + vanilla JS, sin build). La API vive en el mismo dominio bajo `/api/v1`.
